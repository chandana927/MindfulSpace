**MindfulSpace** is a safe, private, and stigma-free digital platform designed specifically for college students in India. It aims to bridge the gap between academic pressure and emotional well-being by providing intuitive tools for mood tracking, journaling, and stress management.

![MindfulSpace Hero Illustration](assets/hero-illustration.png)

## ✨ Features

- **📊 Mood Tracker:** Log your daily emotional state and visualize your journey over time.
- **📓 Personal Journal:** A private space to reflect and express yourself with guided prompts.
- **🌬️ Breathing Exercises:** Step-by-step guidance for techniques like 4-7-8 and Box Breathing to manage anxiety.
- **📈 Emotional Insights:** A dedicated dashboard to identify patterns and triggers in your mental health.
- **🆘 Emergency Helplines:** Instant access to verified Indian mental health support numbers.
- **🔒 Privacy First:** 100% private. No data leaves your device. No judgment, just support.

## 🚀 Getting Started

To run MindfulSpace locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/chandana927/MindfulSpace.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd MindfulSpace
   ```
3. **Open `index.html` in your browser:**
   Double-click the file or use a local server like Live Server (VS Code Extension).

## 🛠️ Tech Stack
